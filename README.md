# aldianyhs

Personal portfolio of Aldian Yohanes. Next.js 16, React 19, Tailwind 4.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- Content lives in `lib/content.ts`.
- Brand tokens and rules are in `BRAND.md`.
- Optional assets: `public/images/profile.jpg`, `public/cv/Aldian-Yohanes-CV.pdf`, and project covers (`public/images/<name>.png`, see `lib/content.ts`).
